The idea

Stack each firm's NK bit-string into a bipartite actor × component network, make it a SAOM's dependent variable, and one scalar K unfolds into four coupled, endogenous degrees.
K_AC

Actor scope

how many components a firm holds

K_CA

Component popularity

how many firms hold a component

K_AA

Actor sociality

firm–firm projection, emergent rivalry

K_CC

Component epistasis

the classical NK K — now endogenous
